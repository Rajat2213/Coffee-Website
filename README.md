## 📌 Features  
✅ **Modern & Responsive Design** – Works on all devices (mobile, tablet, desktop)  
✅ **Smooth Animations** – Engaging user experience with subtle animations  
✅ **Easy Navigation** – Simple & intuitive layout  
✅ **Coffee Menu** – Showcases different coffee options  
✅ **Contact Form** – Allows customers to reach out  

---

## 🚀 Technologies Used  
- **HTML5** – For structuring the webpage  
- **CSS3** – For styling and animations  
- **JavaScript** – For interactivity  
- **FontAwesome** – Icons for a modern look
